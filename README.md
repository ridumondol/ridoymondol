## 🚀 About The Project

This portfolio is built using modern web technologies to deliver a fast, responsive, and visually appealing user experience. It highlights:
- **Hero & About:** Introduction and professional background overview.
- **Projects:** A showcase of my best works with detailed views.
- **Experience & Education:** Professional history and academic credentials.
- **Skills:** Technical proficiencies and tools I use.
- **Contact:** Ways to get in touch with me.

---

## 🛠️ Built With

The project utilizes a modern tech stack:
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript / JavaScript
- **Deployment:** [Vercel](https://vercel.com/)
